# Menengai design system

The visual centre is the club’s people: a clear photographic hero beside a solid cranberry panel. Barlow Condensed supplies compact, large headings; Manrope carries body copy and controls. Both are hosted locally as WOFF2. The design uses warm white, sage meeting panels and a charcoal footer, with restrained rounding and no decorative gradients on the new homepage.

| Token | Value | Use |
|---|---|---|
| Cranberry | #bd164b | Large identity panels and accessible primary buttons |
| Brand bright | #d91b5c | Reference accent, never an altered Rotary emblem |
| Ink | #222b31 | Headings, dark buttons and footer |
| Paper | #faf9f6 | Main background |
| Sage | #e8eee5 | Fellowship and source/context panels |
| White | #ffffff | Navigation, project sections and meeting details |

The cranberry treatment is a site accent, not a replacement masterbrand signature. Official artwork has not been supplied. Text identity is temporary and must be replaced with an authorised club lockup without distortion, cropping, recolouring or an invented wheel.

Spacing uses 8, 16, 24, 32, 48 and 72 px steps, with fluid section spacing. Containers have a 1320 px maximum and responsive gutters. Display text is fluid; long prose stays near 60–65 characters. Buttons have at least 46 px height and a 5 px radius; photographic panels use 8–9 px. Shadows are restrained on retained interior components, absent from homepage content rows.

The header compresses to a menu below 900 px. The hero and major paired sections stack below 760 px. The smallest 320 px layout receives a smaller invitation heading. Keyboard focus is visible. Mobile menu supports first-link focus, bounded Tab navigation, Escape and return focus. Content is visible before JavaScript. Reduced-motion rules disable transitions and smooth scrolling.

The homepage has no animated impact counters, fabricated portraits, testimonials, newsletter form or donation instructions. Historical stories are labelled as archive content. The current leadership limitation is handled on its dedicated page rather than implying a complete approved board.
