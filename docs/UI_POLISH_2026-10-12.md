# Local UI refinement — 12 October 2026

Reviewed the current committed website, including the club masterbrand, Thee Magicals mantra, 2026 event photography, programme updates and officer cards. The working tree was clean at the start. This pass preserves that content and changes presentation locally. No commit, push or deployment was performed.

## Design changes

- Cranberry and the existing display/body fonts remain the identity. The hero has one short masked headline entrance, a clear current photograph, readable event caption and manual previous/next controls. Playback is opt-in, stops on manual selection, pauses on hover/focus, offscreen and in a hidden browser tab, and disables itself under reduced motion.
- Removed overlapping image crossfades, the breathing ellipsis and scroll effects that moved/tinted the copy. Photos are no longer blended into double faces, and reading the opening copy no longer depends on scroll position.
- Moved the six photographic links out of the main image into a dedicated camera rail. On phones it uses native horizontal scrolling and snap alignment; all destinations work without drag interaction.
- Reduced the phone header and opening copy height so photographs appear sooner. The header keeps the supplied lockup; the first-screen Join us action remains in the hero.
- Primary mobile links are larger and separate from secondary destinations. A fellowship visit panel supplies the next step. The page behind the menu is inert while it is open; focus trapping, Escape and focus restoration remain in place.
- Refined event cards, project/photo interactions, active filters, action feedback, meeting panel and mobile title sizing. Touch targets remain at least 44px for the new controls.
- Event browsing opens upcoming when a future occasion exists, and otherwise opens the archive. Dates use the Nairobi day boundary; cancelled occasions do not trigger the upcoming default. The present records include a future medical camp, so the current default remains upcoming. Archive records now have real thumbnail previews.
